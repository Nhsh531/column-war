# מלחמת טורים — שרת אונליין

משחק קלפים לשני שחקנים בזמן אמת, עם חדרים וקוד הצטרפות.
השרת סמכותי: כל הלוגיקה רצה בשרת, כל שחקן רואה רק את היד שלו, והקלף החמישי של היריב מוצג הפוך.

## הקבצים (כולם שטוחים, בלי תיקיות)

```
server.js        השרת: חדרים, WebSocket, טיימר, סנכרון
game-core.js     מנוע המשחק: חפיסה, פוקר, מהלכים, סיום
index.html       הקליינט (מה שנפתח בדפדפן)
package.json     תלויות (express, ws)
render.yaml      הגדרות פריסה ל-Render
.gitignore
README.md        הקובץ הזה
```

---

## העלאה לאינטרנט דרך Render (מהנייד) — שלב אחר שלב

Render נותן אירוח חינמי שתומך ב-WebSocket. השירות "נרדם" אחרי 15 דקות בלי פעילות ומתעורר תוך כ-דקה בכניסה הבאה — מצוין למשחק עם חברים.

### שלב 1 — להעלות את הקבצים ל-GitHub

1. פתחו את **github.com** בדפדפן בנייד והתחברו.
2. לחצו על **+** (למעלה) → **New repository**.
3. תנו שם, למשל `column-war`. אפשר Public או Private. אל תסמנו "Add a README". לחצו **Create repository**.
4. במסך שנפתח לחצו **uploading an existing file** (או **Add file → Upload files**).
5. פרקו את קובץ ה-zip בנייד (באפליקציית הקבצים), ובחרו את **כל** הקבצים: `server.js`, `game-core.js`, `index.html`, `package.json`, `render.yaml`, `.gitignore`, `README.md`.
   (אין צורך ב-`node_modules` — Render יתקין את התלויות לבד.)
6. לחצו **Commit changes**.

### שלב 2 — לחבר ל-Render

1. פתחו **render.com** ולחצו **Get Started** / **Sign up**, והתחברו עם חשבון ה-GitHub (הכי פשוט).
2. לחצו **New +** → **Blueprint**.
3. בחרו את ה-repo שיצרתם (`column-war`). Render יזהה את `render.yaml` וימלא הכל לבד.
4. לחצו **Apply** / **Create**. הפריסה לוקחת כ-2-3 דקות.

> אם אין "Blueprint": בחרו **New + → Web Service**, בחרו את ה-repo, ובהגדרות:
> Build Command = `npm install`, Start Command = `npm start`, Instance Type = **Free**. לחצו Create.

### שלב 3 — לשחק

בסיום תקבלו כתובת כמו `https://column-war.onrender.com`.
שולחים אותה לחבר: אחד לוחץ "צור חדר וקבל קוד", השני מקליד את הקוד — ומשחקים.
(אם השירות היה רדום, ההעלאה הראשונה של הדף תיקח כ-דקה. אחרי זה מהיר.)

## להריץ מקומית (למי שרוצה, ממחשב)

צריך Node.js גרסה 18+.

```
npm install
npm start
```

ואז לפתוח בדפדפן `http://localhost:3000`.
לשחק עם מישהו באותה רשת WiFi: הוא נכנס לכתובת ה-IP המקומית של המחשב, למשל `http://192.168.1.20:3000`.

## הערות

- כל חדר תומך בדיוק בשני שחקנים.
- אם שחקן מתנתק, החדר נסגר והשני מקבל הודעה.
- הטיימר נאכף בשרת: אם נגמר הזמן, המערכת מבצעת מהלך אוטומטי.
- הקליינט עובר אוטומטית ל-`wss` המאובטח כשהאתר ב-`https`, כפי שנדרש ב-Render.
